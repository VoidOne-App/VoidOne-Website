05 / PROJECT

Built in public.
Evolving in public.

VoidOne is an open-source native PC gaming project focused on the software around games a player already owns. Its direction is documented through code, releases and project decisions.

OPEN SOURCE · 2026

THE IDEA

Your games.
Your rules.

VoidOne is not positioned as a game storefront. The project focuses on giving a player a native place to organize, discover and manage games already available on their hardware.

01LOCAL-FIRSTLocal data is a core design consideration.
02NO ADSThe project does not build its UI around advertising.
03OPEN SOURCEDevelopment happens in a public repository.
04PLAYER CONTROLHardware and library remain central.

MANIFESTO

Software should

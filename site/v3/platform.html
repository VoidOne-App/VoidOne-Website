01 / PLATFORM

The platform
around your games.

VoidOne is a native PC gaming platform for organizing and working with games you already own. It is designed as desktop software first: local data, native performance, inspectable code.

NATIVE · LOCAL · OPEN

ARCHITECTURE

A native stack,
not a web wrapper.

The application is built around C++23 and Qt/QML, with SQLite for local persistence and CMake-based automation for reproducible development and release workflows.

COREC++23Native application logic
UIQt / QMLDesktop interface layer
DATASQLiteLocal persistence
BUILDCMake / CIBuild and test automation

DESIGN PRINCIPLES

LOCAL-FIRSTCore workflows can operate around local game data instead of requiring a hosted account.
OPENThe source is public, making the implementation inspectable and contribution possible.
PLAYER CONTROLThe project is centered on games and hardware already owned by the player, rather than a storefront model.
EVOLVINGWebsite claims distinguish current capabilities from future ideas and experiments.

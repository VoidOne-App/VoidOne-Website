FREQUENTLY ASKED QUESTIONS

Clear answers.

No marketing fog. If something is planned rather than implemented, VoidOne says so.

What is VoidOne?

An open-source native PC gaming platform built around games rather than a storefront.

What platform does VoidOne support?

Windows x64 is currently the primary development, testing and release platform. Linux is part of the broader cross-platform direction; macOS is not currently part of the primary packaging pipeline.

Is VoidOne a game store?

No. The project is designed as a platform layer for interacting with gaming environments and libraries the player already owns.

Is VoidOne open source?

Yes. The source code and engineering documentation are publicly maintained on GitHub under the MIT License.

Does VoidOne require AI?

No. AI is intended to remain optional and user-controlled. The core launcher should not depend on a proprietary AI service.

Where can I report a bug or contribute?

Use the project's public GitHub issues and contribution documentation.

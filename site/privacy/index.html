PRIVACY / WEBSITE

LESS DATA.
MORE CONTROL.

This page describes the website behavior in the current source. It is not a promise about how infrastructure providers process their own operational data.

01 / NO USER ACCOUNTS

No sign-in or chat form

The public website does not require an account and no longer offers an online AI chat endpoint. Do not send passwords, private keys or other secrets through public issue trackers or community links.

02 / SITE REQUESTS

Release and status data

Website scripts request same-origin endpoints for release manifests, public repository status and site metadata. The Worker may query public GitHub API endpoints to populate that information.

03 / INFRASTRUCTURE

Cloudflare and GitHub

Requests are served through Cloudflare, and release/status information can be retrieved from GitHub. These providers may process technical request metadata under their own terms and policies.

04 / TRACKING

No analytics intentionally added

The website source does not intentionally include advertising trackers or a first-party analytics script. This does not mean infrastructure providers collect no operational logs.

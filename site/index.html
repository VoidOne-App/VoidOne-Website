05 / FAQ

Questions,
answered plainly.

What is VoidOne?

A native, open-source PC gaming platform for managing and working with games you already own.

Is it a game store?

No. VoidOne is intentionally player-first and library-first rather than a storefront.

Does it require the cloud?

The project is designed around local-first operation. Optional network features should not redefine ownership of your data.

Where can I download it?

Use the downloads page for the current release and packaged artifacts.
